# Spec 12: Pester cases and the .NET tests that cover them

Spec 12 retired Pester as the oracle. Every case in the deleted `factory/tests/*.Tests.ps1` is listed here, by file and
line as of `main` before the cutover (`edd2cb0`), with the unit or integration test that covers it now, pushed down per
[TESTING.md](../TESTING.md) rather than copied. **new** marks a test written in spec 12 for a case nothing covered yet;
each was seen red by a deliberate break of the code it guards. Retired cases tested `FACTORY_IMPL`, which is gone.

The three files that test PowerShell still in the repo are kept, and are not mapped: `setup-azure.Tests.ps1` and
`setup-platform.Tests.ps1` (the setup scripts move to .NET in spec 16) and `simulate.Tests.ps1` (the simulator the
Playwright suite runs).

387 cases are mapped, 18 new tests were written for them, and 30 cases stay in Pester.
